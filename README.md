# 多模态模型攻击与安全评估平台

## 项目定位

本项目已收口为“基于图像模态的多模态模型攻击与安全评估平台”，当前正式版本定位为“多模态目标优先”。

平台主线仅保留以下能力：

- 数据样本管理
- 多模态对抗样本生成
- 统一攻击判定
- 跨模型迁移验证
- 结果可视化与实验记录

研究对象聚焦两类多模态模型：

- CLIP 图文对齐模型
- BLIP 图像描述模型

分类模型（ResNet、VGG、DenseNet 等）仅作为附录基线保留在代码中，不再进入默认主流程。

## 主线功能

### 1. 多模态图像攻击

支持两种白盒图像攻击方法：

- FGSM
- PGD

支持的数据输入方式：

- 自定义图片

### 2. 统一评测定义

平台对攻击结果采用固化判定：

- CLIP：源相似度下降且目标相似度提升达到阈值时，判定为成功
- BLIP：生成描述发生变化，且目标关键词命中/目标重叠提升达到阈值时，判定为成功

### 3. CLIP 鲁棒性分析

对已生成的对抗样本，可在 CLIP 模型上评估：

- 图像特征余弦相似度变化
- 图像特征 L2 距离
- 图文相似度变化与跨模型验证

### 4. BLIP 图像描述评测

对已生成的对抗样本，可在 BLIP 图像描述模型上评估：

- 原图描述 vs 对抗图描述
- 描述变化率
- 描述长度差异与迁移差异

### 5. 样本管理与导出

平台支持：

- 图像样本上传
- 标签 / 备注 / 分组标注
- 样本集合版本快照
- 样本清单 CSV / JSON 导出
- 实验索引 CSV / JSON 导出

### 6. 实验记录与可视化

平台支持保存：

- 原始样本
- 对抗样本
- 扰动图
- 指标结果
- 统一判定结果
- 实验元数据

并在结果页提供表格、柱状图和损失曲线展示。

## 快速开始

安装依赖：

```bash
pip install -r requirements.txt
```

启动 Web 平台：

```bash
streamlit run web/app.py
```

## 附录说明

分类基线实验仍可通过 `scripts/train_classifier.py` 训练 `ResNet` 权重，但它们不再作为默认主线入口。

## 评估指标

平台当前主线支持的核心指标包括：

- 统一攻击成功判定
- 扰动强度：L2 / Linf
- CLIP 图文对齐相似度变化
- BLIP 描述变化率
- 目标关键词命中 / 目标重叠提升

## 评测适配器架构

当前代码已抽出统一评测适配器接口，用于承载多模态验证模块：

- 已接入本地适配器：`CLIP`、`BLIP`
- 已预留未来适配器：`Qwen-VL`、`GLM-4V`

当前版本不启用任何云端依赖，也不包含 API Key 配置逻辑；后续若有合规授权，可在不改动主线攻击流程的前提下补充对应适配器实现。
