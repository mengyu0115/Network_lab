• 快速操作指南

  1. 安装依赖并启动

  pip install -r requirements.txt
  streamlit run web/app.py

  2. 选择攻击模式（左侧）

  - FGSM / PGD / C&W：图像分类攻击
  - Text-FGSM / Text-PGD：文本嵌入攻击
  - MM-CLIP：多模态图文对齐攻击（推荐）

  3. MM-CLIP 最简流程

  - 选择 CLIP模型
  - 上传一张图片
  - 填 源文本（原语义）
  - 可选填 目标文本（目标攻击时）
  - 选择模式：image / text / joint
  - 点 开始多模态攻击

  4. 看结果（“结果分析”页）

  - 源相似度(原图/对抗)、相似度下降
  - 目标攻击时看 目标相似度增益 和 目标攻击成功
  - 查看原图、对抗图、归一化扰动图

  5. 常见问题

  - 模型首次加载慢：正常，后续走本地缓存
  - 图片尺寸报错：已自动适配到 224x224，重启后生效
  - 想看历史元数据：到“历史记录”页查看已保存实验
