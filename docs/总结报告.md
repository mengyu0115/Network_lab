# 多模态模型攻击与安全评估平台 - 总结报告

## 项目概述

### 项目背景

随着人工智能技术的快速发展,多模态大模型在计算机视觉、自然语言处理等领域取得了突破性进展。然而,研究表明这些模型对对抗攻击极为脆弱,存在严重的安全隐患。本项目旨在构建一个系统化的多模态模型攻击与安全评估平台,为AI安全研究提供实验工具和评估方案。

### 项目目标

1. 实现多种经典对抗攻击算法
2. 建立标准化的攻击评估体系
3. 提供可视化的实验平台
4. 形成可复现的实验流程

## 系统架构

本平台采用模块化设计,主要包含以下核心模块:


## 核心功能实现

### 1. 攻击算法实现

#### 1.1 FGSM攻击

**实现特点**:
- 单步梯度攻击,计算效率高
- 支持有目标和无目标攻击
- 可配置扰动强度参数

**关键代码**:
```python
grad_sign = images.grad.sign()
adv_images = images + epsilon * grad_sign
adv_images = torch.clamp(adv_images, 0, 1)
```

**性能表现**:
- 攻击速度: ~0.01秒/样本
- 典型成功率: 70-85%
- 适用场景: 快速评估、对抗训练

#### 1.2 PGD攻击

**实现特点**:
- 迭代优化,攻击效果强
- 支持随机初始化
- 投影到epsilon球内

**关键代码**:
```python
for i in range(num_iter):
    adv_images.requires_grad = True
    loss = compute_loss(model(adv_images), labels)
    loss.backward()
    adv_images = adv_images + alpha * adv_images.grad.sign()
    adv_images = clip_perturbation(images, adv_images, epsilon)
```

**性能表现**:
- 攻击速度: ~0.08秒/样本 (10次迭代)
- 典型成功率: 85-95%
- 适用场景: 标准鲁棒性评估

#### 1.3 C&W攻击

**实现特点**:
- 基于优化的精确攻击
- tanh空间变量替换
- 同时优化扰动大小和攻击成功率

**关键代码**:
```python
w = inverse_tanh_space(images)
optimizer = optim.Adam([w], lr=learning_rate)

for i in range(num_iter):
    adv_images = tanh_space(w)
    l2_dist = (adv_images - images).pow(2).sum(dim=(1,2,3))
    f_loss = compute_f_loss(model(adv_images), labels)
    loss = l2_dist.sum() + c * f_loss.sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

**性能表现**:
- 攻击速度: ~2.35秒/样本 (100次迭代)
- 典型成功率: 95-100%
- 适用场景: 精确安全评估

#### 1.2 文本攻击实现

**实现特点**:
- **文本FGSM**: 在文本嵌入空间的单步梯度攻击
- **文本PGD**: 在文本嵌入空间的多步迭代攻击  
- **通用接口**: 支持CLIP、图像描述等多模态模型
- **专用评估**: 提供文本攻击专用的评估指标

**关键代码**:
```
# 文本FGSM攻击
adv_embeddings = embeddings + epsilon * grad.sign()

# 文本PGD攻击

    adv_embeddings = adv_embeddings + alpha * grad.sign()
```

### 2. 评估指标体系

#### 2.1 攻击成功率 (ASR)

**定义**:
- 无目标攻击: 对抗样本被错误分类的比例
- 目标攻击: 对抗样本被分类为目标类别的比例

**计算公式**:
$$
\text{ASR} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{1}[\text{pred}(x_{adv}^i) \neq y^i]
$$

#### 2.2 扰动强度

**L2范数**:
$$
\|\delta\|_2 = \sqrt{\sum_{i,j,k} (x_{adv}^{i,j,k} - x^{i,j,k})^2}
$$

**L∞范数**:
$$
\|\delta\|_\infty = \max_{i,j,k} |x_{adv}^{i,j,k} - x^{i,j,k}|
$$

#### 2.3 感知质量

**SSIM (结构相似性)**:
$$
\text{SSIM}(x, x_{adv}) = \frac{(2\mu_x\mu_{x_{adv}} + C_1)(2\sigma_{x,x_{adv}} + C_2)}{(\mu_x^2 + \mu_{x_{adv}}^2 + C_1)(\sigma_x^2 + \sigma_{x_{adv}}^2 + C_2)}
$$

**PSNR (峰值信噪比)**:
$$
\text{PSNR} = 10 \log_{10} \frac{1}{\text{MSE}}
$$

#### 2.4 置信度变化

**置信度下降**:
$$
\Delta_{\text{conf}} = \text{Conf}(f(x), y) - \text{Conf}(f(x_{adv}), y)
$$

## 实验结果与分析

### 实验设置

**测试模型**: ResNet-50 (ImageNet预训练)
**测试数据集**: CIFAR-10测试集 (1000张图像)
**评估指标**: ASR, L2, L∞, SSIM, PSNR

### 实验结果

#### 表1: 不同攻击方法的性能对比

| 攻击方法 | 参数设置 | ASR (%) | L2扰动 | L∞扰动 | SSIM | PSNR (dB) | 时间(s) |
|---------|---------|---------|--------|--------|------|-----------|---------|
| FGSM | ε=0.03 | 82.3 | 0.156 | 0.030 | 0.912 | 28.4 | 0.01 |

| 0.10 | 99.2 | 0.324 | 0.100 | 0.765 |

### 结果分析

#### 1. 攻击成功率分析

- **FGSM**: 单步攻击即可达到82.3%的成功率,验证了深度模型的脆弱性
- **PGD**: 通过迭代优化,成功率提升至91.7%,增加迭代次数可进一步提升
- **C&W**: 达到98.5%的极高成功率,几乎可以攻破所有样本

#### 2. 扰动强度分析

- C&W生成的对抗样本扰动最小 (L2=0.089),感知质量最高 (SSIM=0.956)
- PGD在相同L∞约束下,L2扰动小于FGSM,说明迭代优化更加精细
- 扰动强度与攻击成功率存在权衡关系

#### 3. 计算效率分析

- FGSM速度最快,适合实时场景和大规模评估
- PGD在效果和效率间取得平衡,是实用性最强的方法
- C&W计算成本高,但生成的对抗样本质量最优

#### 4. 感知质量分析

- 所有方法生成的对抗样本SSIM均大于0.9,人眼难以区分
- PSNR值均大于28dB,表明扰动在感知上不明显
- C&W在保持高攻击成功率的同时,感知质量最优

### D. 常见问题

**Q1: 为什么攻击成功率很低?**
A: 可能是扰动强度太小,尝试增大epsilon参数。

**Q2: 如何加速攻击过程?**
A: 使用GPU加速,或减少迭代次数。

**Q3: 如何添加自定义模型?**
A: 在`src/models/model_loader.py`中注册新模型。

**Q4: 对抗样本可以迁移到其他模型吗?**
A: 可以,使用`evaluate_transferability`方法测试迁移性。
