# 总结报告

## 1. 项目目标

本项目面向课程要求，构建“基于图像模态的多模态模型攻击与安全评估平台”，正式主线版本定位为“多模态目标优先”。

相较于早期的扩展方向，本项目已经收口到一条完整主线：

- 数据样本管理
- 多模态对抗样本生成
- 统一攻击判定
- 多模态迁移验证
- 结果可视化与实验记录

## 2. 主线功能

### 2.1 多模态图像攻击

平台支持：

- FGSM
- PGD

默认目标模型为：

- CLIP 图文对齐模型
- BLIP 图像描述模型

分类模型与 C&W 仍保留在代码中作为附录基线，但不再进入默认主流程。

### 2.2 统一攻击判定

平台对多模态攻击采用代码固化的成功标准：

- CLIP：源相似度下降与目标相似度提升同时满足阈值
- BLIP：描述变化、目标关键词命中、目标重叠提升满足阈值

### 2.3 多模态迁移验证

平台保留对多模态模型的本地评测能力，用于分析图像扰动是否会迁移到跨模态理解任务。

当前接入：

- CLIP 图文对齐评测
- BLIP 图像描述评测

## 3. 数据与实验管理

平台支持：

- 自定义图片导入
- 样本上传与标注
- 样本集合版本快照
- 对抗样本保存
- 元数据记录
- 历史实验回放
- 实验索引导出

实验结果保存内容包括：

- 原始图片
- 对抗图片
- 扰动图
- 指标结果
- 模型与攻击参数
- 统一判定结果

## 4. 指标体系

主线实验当前使用以下指标：

- 原始准确率
- 攻击后准确率
- 攻击成功率
- L2 扰动
- Linf 扰动
- SSIM
- PSNR
- CLIP 图文相似度变化
- BLIP 描述变化率
- 统一攻击判定结果

## 5. 平台界面

前端采用 Streamlit 实现，当前保留五个核心页签：

- 攻击实验
- 结果分析
- 样本管理
- 历史记录
- 使用说明

其中：

- 多模态攻击页负责配置参数与生成对抗样本
- 结果分析页负责 CLIP 评测和 BLIP 描述对比
- 样本管理页负责上传、标注、版本和导出
- 历史记录页负责查看已保存实验

## 6. 架构说明

当前代码已抽出统一模型评测适配器接口：

- 本地已实现：CLIP、BLIP
- 未来预留：Qwen-VL、GLM-4V

适配器层与图像攻击主流程解耦，因此未来如果需要接入经授权的国内商用多模态模型，可在不改动攻击流程的前提下扩展评测后端。

## 7. 本次收口调整

为了与课程要求保持一致，项目已经删除或隐藏了以下偏离主线的内容：

- 云端黑盒 API 评测页
- 视觉越狱生成器页
- LLaVA 白盒攻击入口
- 手动网页端越狱测试叙事
- ResNet 默认主入口
- CIFAR-10 / MNIST 默认批量攻击入口

这些内容不再作为项目主功能展示。

## 8. 当前完成度

截至当前版本，项目主线已具备以下能力：

- 图像攻击算法实现
- 统一攻击判定
- 数据样本与实验记录管理
- 多模态迁移验证
- Web 可视化展示
- 样本管理与导出

## 9. 后续建议

如果继续完善课程项目，建议优先做以下工作：

1. 在 BLIP 评测基础上补充 caption-level 相似度指标。
2. 在适配器层按授权要求接入 Qwen-VL / GLM-4V，本地平台继续保持无云端强依赖。
3. 根据课程要求继续完善图表化对比与报告导出模板。

## 10. 结论

当前项目已经从“功能扩张”回到“课程主线”，形成了一个可运行、可评估、可记录、可展示的图像模态多模态模型攻击与安全评估平台。

该版本更符合课程对“攻击场景设计、攻击样本构造、算法实现、评估分析、平台展示”的总体要求。
