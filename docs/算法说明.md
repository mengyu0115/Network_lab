# 算法与指标说明

## 1. 技术路线

商业多模态大模型无法获取内部梯度，因此本项目不直接对白盒攻击 Qwen-VL，而采用黑盒迁移评估路线：

```text
本地 surrogate 模型
-> 图像对抗样本生成
-> Qwen-VL 原图/对抗图同任务调用
-> 输出字段与真实答案对比
-> 判断黑盒迁移是否成功
```

其中，本地模型用于产生扰动，Qwen-VL 用于最终鲁棒性评估。

## 2. FGSM

FGSM 是单步梯度攻击方法，沿损失函数对输入图像的梯度符号方向添加扰动：

```text
x_adv = x + epsilon * sign(grad_x L(f(x), y))
```

特点：

- 速度快，适合快速基线实验。
- 扰动强度主要由 `epsilon` 控制。
- 在复杂 OCR 截图上可能不如 PGD 稳定。

报告中可作为和 PGD/C&W 对比的轻量攻击方法。

## 3. PGD

PGD 是迭代式投影梯度攻击，每一步沿梯度方向更新图像，并投影回允许扰动范围：

```text
x_adv^(t+1) = Proj_epsilon(x_adv^t + alpha * sign(grad_x L))
```

平台参数：

```text
epsilon：最大扰动范围
alpha：每一步更新步长
num_iter：迭代次数
```

推荐主实验参数：

```text
epsilon=0.03
alpha=0.01
num_iter=20
```

强扰动补充实验：

```text
epsilon=0.05
alpha=0.01
num_iter=30
```

零扰动对照：

```text
epsilon=0
```

零扰动组应满足 L2=0、Linf=0、SSIM=1、真实答案攻击成功=否。

## 4. C&W

C&W 将对抗样本生成转化为优化问题，在控制扰动幅度的同时推动模型输出变化：

```text
min ||delta|| + c * f(x + delta)
```

特点：

- 计算开销大于 FGSM/PGD。
- 可作为更强攻击方法补充。
- 课程主线建议 PGD 为主，C&W 作为扩展对比即可。

## 5. 本地指标

对抗样本生成页会输出本地指标：

| 指标 | 含义 | 报告使用方式 |
| --- | --- | --- |
| L2 | 原图与对抗图的整体扰动强度 | 证明扰动存在且强度可控 |
| Linf | 单像素最大扰动 | 判断是否超过参数限制 |
| SSIM | 结构相似度 | 说明视觉上是否保持接近 |
| PSNR | 图像质量指标 | 可作为辅助质量分析 |
| Surrogate 预测翻转 | 本地代理模型输出是否变化 | 说明扰动对 surrogate 生效 |

自定义截图不是 ImageNet 分类任务，因此 `原始准确率`、`攻击后准确率` 和传统分类 `攻击成功率` 不作为 Qwen-VL 主实验结论。

## 6. Qwen-VL 黑盒字段指标

Qwen-VL 黑盒评估页将原图和对抗图输入同一模型、同一提示词，比较输出文本。

基础指标：

| 指标 | 含义 |
| --- | --- |
| 回答相似度 | 原图回答与对抗图回答的文本相似度 |
| 输出变化 | 回答相似度低于阈值时为“是” |
| 字段变化数 | key=value 输出中发生变化的字段数量 |
| 数字变化数 | 输出数字缺失或新增的数量 |
| 黑盒迁移成功 | 无真实答案时基于输出变化/关键词变化粗略判断 |

填写真实答案字段后，系统进一步计算：

| 指标 | 含义 |
| --- | --- |
| 原图字段准确率 | Qwen-VL 对原图回答与人工真实答案的匹配比例 |
| 对抗图字段准确率 | Qwen-VL 对对抗图回答与人工真实答案的匹配比例 |
| 准确率下降 | 原图字段准确率减去对抗图字段准确率 |
| 真实答案攻击成功 | 原图足够正确且对抗图使正确字段变错 |

## 7. 严格成功判定

推荐报告采用严格判定：

```text
原图字段准确率 >= 80%
对抗图字段准确率 < 原图字段准确率
存在原本正确但对抗后错误的字段
L2/Linf > 0
```

分类方式：

| 类型 | 判定 |
| --- | --- |
| 严格成功样本 | 满足上面的严格判定 |
| 部分成功样本 | 原图准确率 60%-80%，且对抗后下降 |
| 鲁棒失败样本 | 原图和对抗图都识别正确 |
| 原图困难样本 | 原图字段准确率低于 60%，不计入严格成功 |
| 零扰动对照 | epsilon=0，指标应不显示攻击成功 |

## 8. CLIP/BLIP 附加实验

系统保留 CLIP 图文对齐攻击和 BLIP 图像描述扰动验证：

- CLIP 用于观察图像扰动对图文相似度的影响。
- BLIP 用于观察图像描述是否发生变化。

这两部分只作为附加实验和 baseline，不能替代 Qwen-VL 商业大模型黑盒评估结论。

## 9. 实验记录

每次生成对抗样本会保存：

```text
data/adversarial/<attack>_<timestamp>/
```

内容包括：

- 原图
- 对抗图
- 扰动图
- `metadata.json`
- 本地攻击指标
- Qwen-VL 黑盒评估结果

`data/` 为运行产物，默认不提交 GitHub。最终提交建议上传代码、文档和少量脱敏示例图片。
