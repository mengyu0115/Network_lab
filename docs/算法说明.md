# 算法说明

## 1. 主线范围

本项目算法主线收口为多模态目标优先的图像攻击与评估，保留以下五部分：

- 多模态白盒攻击：FGSM、PGD
- 多模态迁移验证：CLIP、BLIP
- 统一攻击判定
- 样本管理与实验导出
- 攻击结果统计与可视化

## 2. FGSM

FGSM 通过一次梯度反向传播，沿输入梯度符号方向生成扰动：

```text
x_adv = x + epsilon * sign(∇x L(f(x), y))
```

特点：

- 计算速度快
- 适合快速验证模型脆弱性
- 可作为批量攻击的基线方法

平台输出：

- 对抗样本
- L2 / Linf 扰动强度
- 攻击成功率
- CLIP 相似度变化 / BLIP 描述变化

## 3. 统一攻击判定

平台在代码中固化了多模态成功标准：

- CLIP：`源相似度下降 >= 阈值` 且 `目标相似度提升 >= 阈值` 时判定成功
- BLIP：`描述发生变化` 且 `目标关键词命中` 或 `目标重叠提升` 达到阈值时判定成功

该判定结果会写入实验 `metadata.json`，并在结果页和历史页同步展示。

## 4. PGD

PGD 是迭代式图像攻击方法，在每一步沿梯度方向更新，并投影回允许扰动范围：

```text
x_adv^(t+1) = Proj(x_adv^(t) + alpha * sign(∇x L))
```

特点：

- 攻击效果通常强于 FGSM
- 支持步长、迭代次数等参数调节
- 适合做标准鲁棒性评测

平台支持参数：

- `epsilon`
- `alpha`
- `num_iter`

## 5. 附录：C&W 分类基线

C&W 攻击将样本生成转化为优化问题，在尽量控制扰动的前提下提高攻击成功率。

目标形式可概括为：

```text
min ||delta|| + c * f(x + delta)
```

特点：

- 攻击成功率高
- 扰动通常更小
- 计算开销明显大于 FGSM / PGD

该方法仍保留在代码中作为分类基线，不再进入默认主流程。

平台支持参数：

- `c`
- `learning_rate`
- `num_iter`

## 6. 附录：黑盒迁移评测

在白盒分类模型上生成的对抗样本，可进一步输入到其他分类模型中，评估迁移攻击效果。

核心指标：

- 迁移成功率
- 不同目标模型之间的迁移差异

该部分作为附录保留，用于说明旧的分类基线，不再是默认主流程。

## 7. 多模态迁移验证

虽然主线攻击聚焦图像分类模型，但平台保留了对多模态模型的验证能力，用于观察图像扰动是否会跨任务迁移到图文理解能力。

当前包含两类本地验证器：

- CLIP 图文对齐评测
- BLIP 图像描述评测

其中，CLIP 分析内容包括：

- 原图与对抗图的图像特征余弦相似度
- 原图与对抗图的图像特征 L2 距离
- 在固定文本提示下的图文相似度变化

BLIP 分析内容包括：

- 原图描述 vs 对抗图描述
- 描述变化率
- 描述长度差异

代码层已抽出统一评测适配器接口，未来可按同一接口追加 Qwen-VL / GLM-4V 等授权模型评测器，但当前版本不启用云端依赖。

## 8. 指标体系

平台主线当前使用的指标包括：

- 原始准确率
- 攻击后准确率
- 攻击成功率
- L2 扰动
- Linf 扰动
- SSIM
- PSNR
- 黑盒迁移成功率
- CLIP 相似度变化
- BLIP 描述变化率
- 统一攻击判定结果

## 9. 样本管理与导出

平台支持：

- 图像样本上传与标注
- 样本集合版本快照
- 样本清单 CSV / JSON 导出
- 实验索引 CSV / JSON 导出

## 10. 输出结果

每次实验会输出并保存：

- 原始图片
- 对抗图片
- 扰动图
- 实验参数
- 指标结果
- 历史记录元数据

以上结果统一保存到 `data/adversarial/` 目录中，便于重复实验与结果复查。
